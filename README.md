# videa

This is a fork of https://github.com/cufarvid/lazy-idea.

## Installation

Clone the repository to `~/.config/idea/videa`

```bash
mkdir -p ~/.config/idea
git clone https://github.com/g4l9/videa ~/.config/idea/videa
```
